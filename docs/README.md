# Documentation

This directory contains analytical and reporting documents detailing the design, difficulties, execution, and timing profiles of the Plastic Sorting Project.

## Files
- `Project_Report.pdf`: The official Project Report formatted with a structured overview of the problem statement, ML methodology, MCU architecture, preprocessing pipeline, challenges, and final performance metrics.
- `Project_Report.md`: Markdown version of the Project Report.
- `embedded_debug_analysis.md`: Detailed logs and explanations on fixing compiler constraints (C89 vs C99) and hardware layout logic bugs during firmware integration.
- `Timing_Optimization_plan_DualCore.md`: Plan mapping out the process of shifting inference from CPU1 to CPU2 to achieve an ultra-fast pipelined throughput.
